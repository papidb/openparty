## 2026-03-07 Final QA run findings
- API room create/show payload uses top-level keys (`room_id`, `invite_code`) instead of nested `room` object.
- Channel protocol requires Phoenix socket frame arrays (`[join_ref, ref, topic, event, payload]`); object-shaped frames do not receive replies.
- `register_user/1` sets email/display_name only; password must be set via `update_user_password/2` for token login tests.
- `confirmed_at` field is `:utc_datetime`; use second-truncated or `User.confirm_changeset/1` when confirming via scripts.
